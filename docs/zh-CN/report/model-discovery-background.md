# 按来源自动同步模型

账号和聚合 API 现在都可以单独开启后台模型同步（#515）。默认关闭，不会因为打开页面、导入账号或添加连接而自动请求模型列表。

## 使用方法

1. 管理员进入「账号」或「聚合 API」，点击目标来源的「后台同步」按钮。
2. 设置同步间隔，点击「启动后台同步」。默认 60 分钟，允许 5–10080 分钟。
3. 启动后立即安排一次同步，之后由服务后台定时执行。弹窗展示运行状态、最近成功/失败、发现及新增数量、下次执行时间。
4. 点击「停止后台同步」取消该来源后续同步。停止不删除已经加入的模型或路由。

同步由服务执行，关闭页面不影响任务；退出整个桌面服务或停止独立服务会停止执行。开关、间隔和最近结果持久化保存，服务再次启动时恢复已启用任务。任务失败会延后重试，不进行高频循环重试。

## 同步范围

- 同步使用所选来源的现有认证、代理及模型发现接口，仅请求模型目录，不运行模型推理或连接测试。
- 账号用于获取它可见的模型列表；关联后的模型使用现有账号池路由，发现账号不等于推理固定账号。
- 聚合 API 新增的路由指向所选连接。
- 只创建缺失的模型和路由。已有名称、价格、排序、能力设置、启停状态与其他路由均保留，包括同步期间发生的人工修改。
- 不删除本轮目录未返回的模型。新模型沿用手动关联的默认配置（文本能力、价格未知），价格和实际能力需要自行核实；返回模型列表也不代表每个模型都能实际推理。
- 原有「获取账号模型」「拉取并关联模型」仍可用于一次性获取后手动选择。

来源删除或停用后不会继续对该来源发送发现请求。停用任务与写入目录协调：停止操作返回后，已取消的旧任务不能再开始追加模型。此前已经完成的写入不会回滚。

## 权限与部署

列表和设置接口均仅管理员可用，桌面和 Web 使用相同服务端权限检查。配置只保存来源 ID 和任务状态，不复制账号令牌或聚合密钥；上游错误只记录脱敏的阶段信息。

任务配置存储在现有 `app_settings`，兼容 SQLite 和 SeaORM 配置存储，无需新增环境变量。RPC 为 `modelDiscovery/list` 与 `modelDiscovery/update`；写入设置不自动重放。`sourceKind` 使用 `openai_account` 或 `aggregate_api`。

调度器在单个服务进程内最多同时执行 2 个来源，同一来源不会重复并发执行。本实现没有跨进程租约；共享数据库的多个服务实例应只由一个实例运行此任务，不能把进程内去重视为分布式任务保证。
